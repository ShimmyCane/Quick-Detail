# Hatch patterns

One file per material pattern. Each file gives four things:

1. **App definition.** The key and parameters in `sketch/hatch.js` (`SK.HATCHES`), with the line numbers.
2. **Hand-drawn convention.** How the user draws the same material by hand, from their own sketches, with the detail name and date.
3. **Decision.** Which version we use for markup, and why.
4. **Open questions.**

Current files: `earth.md`.
