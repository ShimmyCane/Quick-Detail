# Graphic scale, v5 (31 Oct)

Four equal blocks, alternating ink and paper. Each block is a quarter of the labelled length, so the blocks are the same real length and the bar stays true to scale. The label at the end gives the total.

- `scale-1-inch.png`, `scale-6-inches.png`, `scale-12-inches.png`, `scale-2-feet.png`: captured from the app as the zoom changes.
- `scale-8-feet-sample.png`: a rendering with the same bar style. The app's zoom floor (one-sixth of the detail's default zoom) does not reach 8 feet for a 3" = 1'-0" detail.
