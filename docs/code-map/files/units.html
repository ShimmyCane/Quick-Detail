sketch/units.js

Pure logic · 125 lines · Library 2 of 14 in the load order.

What it does

scales and units. The sheet is drawn in real inches; the scale only sets how big notes,
arrows and ticks are (they keep a fixed size on paper), and how big the sheet starts on screen.
