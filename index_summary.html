Quick Detail: code map

How the detail editor is put together, where each part lives, and which values you can change. Line numbers match the files as of the MVP (2026-10-23).

1. How a drawing flows

Detail JSON

The one source of truth: elements (geometry, graphics, meaning, intent, logic), relationships, and review items. model.js

Primitives

Each element becomes paths, circles, arcs, and text in real units, with pen widths in paper mm. Hatches are clipped here. primitives.js

Outputs

The screen and SVG (svg.js), PDF and DXF (export.js), and PNG/JPEG (SVG drawn onto a canvas). All read the same primitives, so they match.

Editor

Tools and snapping write new elements; panels edit meaning and relationships; rule checks read them back. app.js, review.js

Every edit goes through mutate() in app.js. It refuses changes to locked details, takes an undo snapshot, autosaves to browser storage, and redraws.

5. Values you can change

WhereVariableWhat it doesHow to change it
Settings gearsettings.pens.P1–S1Pen widths in paper mm (default 0.13 / 0.18 / 0.25 / 0.35 / 0.50 / 0.25).Match your office pen table. Affects screen, PDF, SVG, and images.
Settings geartextMMDefault note height on paper (2.5 mm ≈ 3/32").Use 2.0–3.0. Each note can override it in Selection.
Settings geargridIn, gridMMSnap grid size per unit system.1/4" or 1/8" suits most details.
Settings gearminScreenPxThinnest line on screen when zoomed out.0 shows exact weights; 0.75–1 keeps fine pens visible. Exports are not affected.
Settings geardpiPNG/JPEG resolution.150 for email, 300 for print. Images are capped at 8000 px per side.
vocab.jsQD.HATCHES[*].familiesHatch angle and spacing in paper mm, so density looks the same at any scale.Smaller spacing gives a denser hatch. dots spaces the stipple.
vocab.jsQD.MATERIALS[*]Each material's default pen, hatch, role, and line or region kind.Add entries for your own materials; ids are lower_case_words.
vocab.jsQD.PENS[*].dxfColorDXF layer color per pen, for a CAD plot-style table.Change to match your CTB file.
vocab.jsQD.LINETYPESDash patterns in paper mm, also written into the DXF linetype table.Edit the arrays (dash, gap, dash, gap).
primitives.jsarrow L/W, tick t, title strip sizesArrowhead 2.2 × 1.5 mm, dimension tick 2.5 mm, title 3.5 mm text.Values are paper mm passed through cx.mm().
style.css--bg, --mint, --peach, --sky, --butter, --sagePastel interface colors (the drawing itself stays black and white).Change in :root.
style.css--sel, --draftSelection blue and in-progress coral on the drawing.Pick colors that read clearly against black linework.
style.css--touchMinimum button height (44 px).Raise to 48–56 for easier tapping on iPad.
style.css.cols gridRight panel column width (370 px).Wider panels leave less drawing space.
Browser storageqd.current, qd.library, qd.settings, qd.closedPanelsAutosaved detail, library, settings, and collapsed panels.Clearing site data removes them. Download JSON for real backups.
