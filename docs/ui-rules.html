2. Rules we follow now

Touch targets are big. Every button is at least 44 px, and 48 px on the recording and panel buttons. Done.
Recording sits beside the pen. The scene button and the microphone are in the left toolbar, next to the colours. Done.
The microphone starts muted. Nothing is opened or captured until the user unmutes. While muted, audio and speech are paused, not just hidden. Done.
Select is a tool, not a mode you forget. The ↖ button (or V) turns select on and drawing off. Tap picks, drag moves, the corner scales, the round handle turns, and empty space pans. Picking a colour or weight goes back to drawing. Done.
The toolbars can be hidden. The ⤢ button hides both toolbars for more room. A setting hides them while an object is selected. The same button brings them back. Done.
New sketches are numbered and marked. They are named Untitled 0001, 0002, and so on, tagged TEMP until renamed. Done.
Deleting is recoverable. A delete moves the detail to the recycle bin. The question has a "don't ask for 5 minutes" choice. The bin restores or empties. Done.
Panels look the same. Each panel has a title, a Close button, and sections that each start with a short line of help. Done for Project info, Settings and the library. The Log panel is not checked yet. open
Underlays are faint and kept off prints. Images and blocks are underlays. They can be scaled, faded and moved, and they stay out of the print unless set to print. Done.

3. Rules still open

Permission memory. The browser decides how long a microphone permission lasts. The app asks once per page load. On iPad Safari, expect to be asked again. open: test on the iPad
Phone real estate. On a phone, the title block and the chips still take space when a detail is open. open: test on a phone
Rotation on text. Notes and dimension text stay upright when their item is turned. open: decide whether text should turn
Panel layout. Panels should share one grid, with the same spacing, title size and button row. open

4. How to use this page

When a screen decision is made, add or change a rule here, and link the commit. When a rule is built and tried on the device it is for, change "open" to "done".
